# TrailBase

TrailBase — открытый каталог GPX-треков с картой, поиском, классификацией и
каталогом известных локаций. Пользователи смогут загружать маршруты через веб и
ботов Telegram/Max, а публикации будут проходить модерацию.

> **Статус:** проект находится на этапе спецификации. Архитектурные решения и
> проверяемые инварианты зафиксированы, реализация приложения ещё не начата.
> Следующий срез — M01 Foundation.

## Возможности

- загрузка и безопасный разбор GPX;
- приватные черновики и модерируемые неизменяемые версии треков;
- интерактивная карта с адаптивной доставкой геоданных;
- полнотекстовый, географический и фасетный поиск;
- каталог POI с OSM provenance;
- bot-first аутентификация через Telegram и Max;
- уведомления и управление основными сценариями через веб-интерфейс.

## Архитектура

Backend строится на Clojure и Java 25. Основные сервисы запускаются через Docker
Compose и используют PostgreSQL/PostGIS, Valkey и S3-совместимое объектное
хранилище. Веб-интерфейс основан на серверном HTML, htmx, Alpine и MapLibre.
Длительные операции выполняются отдельными workers.

Разработка разбита на вертикальные срезы:

```text
M01 Foundation
  → M02 Auth
  → M03 GPX Upload
  → M04 Catalog Render
  → M05–M08 POI, Search, Classification, Photo/Elevation
```

criteria в Roadmap. Не считайте рекомендации из Grill-me Checkpoint принятыми
решениями без явного подтверждения.
