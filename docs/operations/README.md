# Operations

Runbooks появляются здесь, когда для операции есть повторяемая процедура. Пока
нормативные требования к deploy, monitoring, backup и incident signals находятся в
[platform contract](../contract/platform.md) и
[deployment control](../contract/platform/deployment-control.md).

Этот каталог не задаёт продуктовых или архитектурных решений.
